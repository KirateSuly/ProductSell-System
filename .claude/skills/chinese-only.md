# 中文交流规则

## 核心要求

1. **思考过程必须使用中文**：所有分析和推理过程（包括 `<thinking>` 标签内的内容）必须使用简体中文。

2. **回复内容必须使用中文**：所有对用户的输出必须使用简体中文，包括解释、代码注释、计划文档、记忆文件等。

3. **代码注释使用中文**：编写或修改代码时，注释应使用中文（除非是公开 API 或库代码需要英文）。

4. **文件内容**：创建的 markdown 文件、计划文件、记忆文件等，正文内容使用中文。

5. **唯一例外**：代码本身（变量名、函数名、类名等标识符）保持英文，遵循编程规范。

## 执行

此规则始终生效，无需用户每次提醒。
