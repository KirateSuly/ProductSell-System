# AI 智能问答助手 实现计划（Spring AI 方案）

## Context

为进销存管理系统接入一个内嵌侧边 AI 对话窗口。AI 固定扮演"销售进销存顾问"角色，能够用自然语言回答用户关于业务数据（营收、库存、订单等）的查询，并指导系统操作。后端代理调用公有大模型 API，实时注入数据库中的真实业务数据，严格约束 AI 不虚构数据、不回答无关闲聊。

### 当前状态
- 前端：Vue 3 + Element Plus + Pinia + Axios，MainLayout 布局为 el-aside(左) + el-header + el-main
- 后端：Spring Boot 3.2.5 + Spring Security JWT + MyBatis Plus
- 已有完整的统计 API（overview, sales-trend, top-products, category-sales, order-status）
- 无任何 AI/聊天相关代码

### 为什么选择 Spring AI

| 维度 | RestTemplate 方案 | Spring AI 方案 |
|------|------------------|---------------|
| 依赖 | 无额外依赖（RestTemplate 自带） | 需添加 `spring-ai-openai-spring-boot-starter` |
| 配置 | 需手写 `AIConfig.java` 创建 Bean | application.yml 配置即可，自动装配 `ChatModel` |
| 调用方式 | 手动拼 JSON body → `restTemplate.postForEntity()` → 手动解析 | `chatModel.call(new Prompt(messages, options))` 一行搞定 |
| 代码量 | 较多（~50 行样板代码） | 较少（~10 行核心逻辑） |
| 安全性 | API Key 可通过环境变量注入 | 同（Spring AI 同样从 yml/环境变量读取） |
| 模型切换 | 需改 url + 请求格式 | 改 starter 即可（openai → ollama → vertex） |
| 流式响应 | 需手动处理 SSE | 内置 `Flux<String>` 流式支持 |
| 可观测性 | 需自行埋点 | 内置 Micrometer metrics |
| 成熟度 | Spring 生态原生方式 | Spring 官方 AI 框架，活跃维护 |

**结论**：Spring AI 比手写 RestTemplate 代码更干净、更 Spring 原生、更易扩展。本项目就是 Spring 生态项目，用 Spring AI 是天作之合。

### 步骤 4：后端 — AI Service（核心 Prompt 工程）

这是整个方案最关键的步骤。

**新建**: `backend/src/main/java/com/productsell/service/AIService.java`
```java
public interface AIService {
    ChatResponse chat(ChatRequest request);
}
```

**新建**: `backend/src/main/java/com/productsell/service/impl/AIServiceImpl.java`

核心实现。对比 RestTemplate 方案的最大区别：**不用手写 HTTP 调用，全部交给 Spring AI**。

```java
@Service
@RequiredArgsConstructor
public class AIServiceImpl implements AIService {

    private final ChatModel chatModel;              // Spring AI 自动注入
    private final StatisticsMapper statisticsMapper;

    @Override
    public ChatResponse chat(ChatRequest request) {
        // 1. 查询真实业务数据
        Map<String, Object> bizData = buildBusinessData();

        // 2. 构建 System Prompt（角色 + 规则 + 实时数据）
        String systemContent = buildSystemPrompt(bizData);

        // 3. 拼接消息列表
        List<Message> messages = new ArrayList<>();
        messages.add(new SystemMessage(systemContent));   // System Prompt
        if (request.getHistory() != null) {
            for (var h : request.getHistory()) {
                if ("user".equals(h.get("role"))) {
                    messages.add(new UserMessage(h.get("content")));
                } else if ("assistant".equals(h.get("role"))) {
                    messages.add(new AssistantMessage(h.get("content")));
                }
            }
        }
        messages.add(new UserMessage(request.getMessage())); // 当前用户消息

        // 4. 调用 LLM（一行代码！Spring AI 处理序列化、HTTP、反序列化）
        var prompt = new Prompt(messages);
        var chatResponse = chatModel.call(prompt);
        String reply = chatResponse.getResult().getOutput().getContent();

        // 5. 封装返回
        ChatResponse result = new ChatResponse();
        result.setReply(reply);
        result.setRefused(false);
        return result;
    }

    // ========== 以下方法同 RestTemplate 方案 ==========
}
```

#### 4.1 固定 System Prompt 设计（同前）

```
你是一个专业的进销存管理系统顾问，只能回答与销售、库存、商品、订单、客户管理相关的问题。

## 核心规则（必须严格遵守）
1. 你只服务于"商品进销存管理系统"的业务咨询。
2. 如果用户询问与进销存业务无关的问题（如天气、闲聊、编程、娱乐、政治等），回复："抱歉，我是销售进销存顾问，只能回答商品管理、库存、订单、客户、销售统计等相关问题。请提出业务相关的问题。"
3. 所有数据必须基于下方【当前系统数据】中的真实数字进行分析。
4. 如果用户询问的数据在【当前系统数据】中不存在，回复："暂无该统计数据"。
5. 严格禁止虚构或编造任何金额、数量、日期、人名等数据。
6. 回答中涉及金额时，必须标注货币单位（元/人民币）。

## 你能做的事情
- 查询和分析销售统计（营收、订单量、趋势）
- 分析库存状况（在售/停售、库存不足预警）
- 查询订单状态分布
- 分析客户数据
- 热销商品排行分析
- 指导用户操作系统功能（如何添加商品、如何创建订单等）

## 回答格式要求
- 用清晰的标题分段（如：### 营收概况、### 库存分析）
- 数字用表格或列表形式展示，标注清楚指标名称、数值、单位、对比
- 分析类回答给出简要的趋势解读或建议
```

#### 4.3 防 AI 乱答的多层防护（同前）

| 层级 | 策略 | 说明 |
|------|------|------|
| System Prompt | 角色锁定 + 规则约束 | 第一道防线，明确边界 |
| 数据注入 | 只提供真实 DB 数据 | 不给 AI 任何"想象空间" |
| ChatOptions | temperature=0.3, maxTokens=1500 | 低温度减少编造，Token 限制防长篇 |
| 后置过滤 | 可选：正则检测是否含"暂无该统计数据" | AI 应自觉遵守 |

### 步骤 5：后端 — AI Controller

**新建**: `backend/src/main/java/com/productsell/controller/AIController.java`

```java
@Tag(name = "AI 智能问答", description = "内嵌 AI 助手对话接口")
@RestController
@RequestMapping("/api/ai")
@RequiredArgsConstructor
public class AIController {

    private final AIService aiService;

    @Operation(summary = "发送对话消息")
    @PostMapping("/chat")
    public Result<ChatResponse> chat(@RequestBody @Valid ChatRequest request) {
        return Result.success(aiService.chat(request));
    }
}
```

**安全**：`/api/ai/**` 不在 SecurityConfig 白名单中，自动被 Spring Security 拦截要求 JWT 认证。无需修改 SecurityConfig。

### API 差异发现与修正

Spring AI **1.0.0-M6** 中 `AssistantMessage` 继承自 `AbstractMessage`，获取文本内容的方法是 **`getText()`** 而非 `getContent()`。已在 `AIServiceImpl.java:83` 修正：

```java
// 错误（编译失败）
String reply = aiResponse.getResult().getOutput().getContent();

// 正确
String reply = aiResponse.getResult().getOutput().getText();
```
